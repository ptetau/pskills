# R4 · pdlc project dashboard

The pdlc state of the project "ledger" is in `changes.json` (each change and its stage),
`questions.json` (open questions for the user), and `intents.json`.

Reader: the project owner, at the start of the day. They need to see where each change
is in the pipeline, what is stuck, which questions wait for them, and how far each intent
has come.
