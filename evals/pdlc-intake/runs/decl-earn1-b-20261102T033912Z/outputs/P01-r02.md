# JOB-report-word-frequencies · See how often each word appears in a file

Status: active

## Who and why

A person at a terminal runs `wordfreq FILE`. They want to see how often each word appears
in the file, most common first.

The person can also run `wordfreq --top N FILE`. They want to see only the N most common
words. These requirements cover the option:

- R4 (top option prints N words)
- R5 (invalid N is an error)
- R6 (missing N is an error)
- R7 (N is checked before the file is read)
- R8 (option position)

## Relies on

- Capabilities: CAP-word-counting
- Design: DES-errors

## Code map

- wordfreq/cli.py
- wordfreq/__main__.py
- wordfreq/__init__.py

## Interface

- `wordfreq [--top N] FILE` · command · `wordfreq/cli.py` · proposed
  - in: the path of a file, and an optional number N, greater than zero, after `--top`
  - out: on standard output, one line for each word, with the word, a space, and the count. The exit code is 0.
  - errors:
    - `no code` · `usage: wordfreq FILE` · exit 2 · stderr
    - `no code` · `error: cannot read <path>` · exit 2 · stderr
    - `TOP_INVALID` (assumed) · `error: --top needs a whole number greater than zero` · exit 2 · stderr

### Test seams

none

## Requirements

### JOB-report-word-frequencies.R1 · Prints each word with its count

Status: built · Intents: none · Source: recon

The command prints one line for each word: the word, a space, and the count. The most
common word comes first, and equal counts are in alphabetical order.

- Given a file with `the cat and the hat and the bat`, when the person runs `wordfreq FILE`, then standard output is `the 3`, `and 2`, `bat 1`, `cat 1`, `hat 1`, one on each line. The exit code is 0.

Seen in: wordfreq/cli.py:21

### JOB-report-word-frequencies.R2 · Unreadable file is an error

Status: built · Intents: none · Source: recon

When the file cannot be read, the command prints one error line and exits with code 2.

- Given a path that does not exist, when the person runs `wordfreq /no/such/file.txt`, then standard error is `error: cannot read /no/such/file.txt`. Standard output is empty, and the exit code is 2.

Seen in: wordfreq/cli.py:18

### JOB-report-word-frequencies.R3 · Wrong argument count prints usage

Status: built · Intents: none · Source: recon

When the command gets no argument, or more than one, it prints a usage line and exits with code 2.

- Given no arguments, when the person runs `wordfreq`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.

Seen in: wordfreq/cli.py:11

### JOB-report-word-frequencies.R4 · The top option prints only the N most common words

Status: proposed · Intents: IN-0001

With `--top N`, the command prints only the first N lines that it prints without the option. When the file has fewer than N words, the command prints all of them.

- Given a file with `the cat and the hat and the bat`, when the person runs `wordfreq --top 2 FILE`, then standard output is `the 3` and `and 2`, one on each line. The exit code is 0.
- Given a file with `the cat and the hat and the bat`, when the person runs `wordfreq --top 1 FILE`, then standard output is `the 3` and the exit code is 0.
- Given a file with `the cat and the hat and the bat`, when the person runs `wordfreq --top 10 FILE`, then standard output is the same as without the option.
- Given an empty file, when the person runs `wordfreq --top 3 FILE`, then standard output is empty and the exit code is 0.

### JOB-report-word-frequencies.R5 · A value that is not a whole number above zero is an error

Status: proposed · Intents: IN-0001

When N is not a whole number greater than zero, the command prints one error line and exits with code 2. Only the numerals 0 to 9 make a whole number (assumed).

- Given any file, when the person runs `wordfreq --top 0 FILE`, then standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2.
- Given any file, when the person runs `wordfreq --top -3 FILE`, then standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2.
- Given any file, when the person runs `wordfreq --top 2.5 FILE`, then standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2.
- Given any file, when the person runs `wordfreq --top abc FILE`, then standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2.

### JOB-report-word-frequencies.R6 · A missing value is an error

Status: proposed · Intents: IN-0001

When `--top` has no value after it, the command gives the same error as for an invalid N (assumed).

- Given any file, when the person runs `wordfreq FILE --top`, then standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2.

### JOB-report-word-frequencies.R7 · The value is checked before the file is read

Status: proposed · Intents: IN-0001

When N is invalid and the file does not exist, the command gives the error for N, not the error for the file (assumed).

- Given a path that does not exist, when the person runs `wordfreq --top 0 /no/such/file.txt`, then standard error is `error: --top needs a whole number greater than zero` and the exit code is 2.

### JOB-report-word-frequencies.R8 · The option can come before or after the file

Status: proposed · Intents: IN-0001

The person can write `--top N` before the file path or after it (assumed).

- Given a file with `the cat and the hat and the bat`, when the person runs `wordfreq FILE --top 2`, then standard output is `the 3` and `and 2`, one on each line. The exit code is 0.
