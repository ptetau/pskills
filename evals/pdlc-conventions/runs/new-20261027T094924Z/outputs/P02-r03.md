````markdown
# DES-number-format · Numbers show as plain digits

Status: agreed · Default: no

## Rule

Each number in the output of wordfreq shows as plain digits in base 10 (assumed). The number has no thousands separator, no sign, no padding, and no unit.

A line of output has the word, one space, and the number. The locale of the system does not change the format.

## Example

The word `the` appears 1200 times, and wordfreq prints `the 1200`. The output never shows `the 1,200` or `the   1200`.

## Why

A line with plain digits is easy to read and easy to parse. For example, `sort` and `awk` can read the count with no clean-up. A fixed format also keeps the output the same on each system.

## Requirements

### DES-number-format.R1 · No thousands separator

Status: proposed · Intents: IN-0001

- Given a file with the word `the` 1200 times, when `wordfreq FILE` runs, then the first line is `the 1200`.

### DES-number-format.R2 · No padding

Status: proposed · Intents: IN-0001

- Given a file with `the` 1200 times and `and` 3 times, when `wordfreq FILE` runs, then the second line is `and 3`.
````
