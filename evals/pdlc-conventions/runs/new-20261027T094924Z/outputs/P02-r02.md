# DES-number-format · How numbers show in the output

Status: agreed · Default: no

## Rule

Write each whole number in the output of wordfreq as plain digits (assumed). Thus, a
script can read the output.

- Do not add a thousands separator. Write `1200`, not `1,200`.
- Do not add leading zeros or padding. Write `7`, not `007` or ` 7`.
- Do not add a plus sign or a unit.

This rule covers whole numbers. Today, the only number in the output is the count of a
word. A number of another kind, such as a percentage, gets its own rule when it first
appears.

## Example

A file with the text "the cat and the hat and the bat" gives these lines:

```
the 3
and 2
bat 1
cat 1
hat 1
```

A word that appears 1200 times gives the line `the 1200`, not `the 1,200`.

## Why

A script can read plain digits with `sort -n` or `awk`. A separator or padding breaks such
a script. Plain digits are also what wordfreq prints today, so no user sees a change.

## Requirements

### DES-number-format.R1 · Counts print as plain digits

Status: proposed · Intents: IN-0001

- Given a file that has the word "the" 1200 times, when the user runs `wordfreq FILE`, then the output is `the 1200`.
- Given a file that has the word "cat" 7 times, when the user runs `wordfreq FILE`, then the output is `cat 7`.
