# DES-number-format · How wordfreq shows numbers

Status: agreed · Default: no

## Rule

Each number that wordfreq prints shows as plain digits (assumed), to keep the output easy
for scripts to read. A number has no thousands separator, no padding, and no unit. A whole
number has no decimal point. One space separates the word from its count.

## Example

For a word that appears 3 times, wordfreq prints `cat 3`. For a word that appears 1200
times, wordfreq prints `the 1200`. It does not print `the 1,200` or `the 1 200`. It does
not print `cat    3`.

## Why

A script can sort, add, or compare plain digits with no cleanup. The code does this today,
and the README describes it. A written rule keeps every later number in the output the same.

## Requirements

### DES-number-format.R1 · A count shows as plain digits

Status: proposed · Intents: IN-0001

A count shows as plain digits, with no separator and no padding.

- Given a file where "the" appears 1200 times, when the user runs `wordfreq FILE`, then
  the line for "the" is `the 1200`.
- Given a file where "the" appears 1200 times and "cat" appears 3 times, when the user
  runs `wordfreq FILE`, then the line for "cat" is `cat 3`.
