# DES-number-format · How numbers show in the output

Status: agreed · Default: no

## Rule

Print each number in the output of wordfreq as a whole number in plain digits (assumed),
because the current output already does this. Do not group the digits with a separator.
Do not pad the number with spaces or zeros.

Today the only number is the count of a word. A line of output is the word, one space, and
the count.

## Example

In `tests/test_cli.py`, the word "the" appears 3 times, and the line is `the 3`. The word
"the" appears 1200 times in a longer file. Then the line is `the 1200`. The line is not
`the 1,200`, `the 01200`, or `the   1200`.

## Why

A plain number is the same in every locale, and a script can read the number as it is. For
example, `sort -n` and `cut -d' ' -f2` work on the output with no clean-up.

## Requirements

### DES-number-format.R1 · No thousands separator

Status: proposed · Intents: IN-0001

- Given a file where "a" appears 1200 times, when wordfreq runs, then the line for "a" is `a 1200`.

### DES-number-format.R2 · No padding

Status: proposed · Intents: IN-0001

- Given a file where "a" appears 12 times and "b" appears 3 times, when wordfreq runs, then the lines are `a 12` and `b 3`.
