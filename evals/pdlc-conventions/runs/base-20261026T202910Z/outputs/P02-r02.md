````
# DES-number-format · How wordfreq shows numbers

Status: agreed · Default: no

## Rule

wordfreq writes each count as plain decimal digits (assumed). The count has no thousands
separator and no padding. Any other number in the output follows the same rule (assumed).

An output line is a word, one space, and the count. That one space is the only space
between the word and the count.

## Example

The text `the cat and the hat and the bat` gives the line `the 3`. If the word `the` appears
1204 times, the line is `the 1204`. The line is not `the 1,204` and not `the  1204`.

## Why

Scripts read the output of wordfreq. Tools such as `sort -n` and `awk` misread a
thousands separator. The code and the README already show plain digits, so the convention
needs no change to the code.

## Requirements

### DES-number-format.R1 · Count has no separator

Status: proposed · Intents: IN-0001

- Given a text where the word `the` appears 1204 times, when wordfreq prints the counts,
  then the line for `the` is exactly `the 1204`.

### DES-number-format.R2 · Count has no padding

Status: proposed · Intents: IN-0001

- Given the counts 1204 for `the` and 7 for `cat`, when wordfreq prints them, then the
  line for `cat` is exactly `cat 7`.
````
