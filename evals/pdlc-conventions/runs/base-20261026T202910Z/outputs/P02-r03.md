# DES-number-format · How wordfreq shows numbers

Status: agreed · Default: no

## Rule

wordfreq writes each number in its output as plain digits (assumed), because other
programs read the output. A number has no thousands separator, no padding, and no leading
zero. The output does not depend on the locale of the machine.

This rule covers whole numbers. wordfreq prints no other kind of number today. The first
feature that prints a number with a fraction must add its format to this rule.

## Example

The word `the` appears 1200 times, and the word `cat` appears 3 times. wordfreq prints
these lines:

```
the 1200
cat 3
```

## Why

Scripts and other tools read the output of wordfreq. Plain digits are the same on every
machine, and every tool can read them. A separator or padding can break a tool. A
separator or padding also breaks the README line "a word, a space, and the count".

## Requirements

### DES-number-format.R1 · Count with no separator

Status: proposed · Intents: IN-0001

- Given a file in which the word `the` appears 1200 times, when the person runs
  `wordfreq FILE`, then the line for `the` is `the 1200`.

### DES-number-format.R2 · Count with no padding

Status: proposed · Intents: IN-0001

- Given a file with `the` 12 times and `cat` 3 times, when the person runs `wordfreq FILE`,
  then the lines are `the 12` and `cat 3`.
- Given the same file, when the person runs `wordfreq FILE`, then each line has one space.
  The space is between the word and the count.
