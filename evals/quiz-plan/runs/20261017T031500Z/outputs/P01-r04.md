## Intent

The nightly sync reads settlement pages from the payments API with `HttpClient.get`. Today, one timeout from the API fails the nightly sync. Then a person must run the sync again by hand.

When this plan is done, `HttpClient.get` tries a failed request again, with a growing wait between the tries. A short blip from the payments API no longer fails the nightly sync. The log shows each retry.

**Not doing:**

- A retry of `HttpClient.post`. A retry of the refund POST could pay a customer twice.
- A retry of a 4xx response.
- A change to `jobs/refund_worker.py`.
