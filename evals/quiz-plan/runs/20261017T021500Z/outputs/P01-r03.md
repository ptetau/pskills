## Intent

One timeout from the payments API fails the nightly sync. A person then runs the sync again by hand.

After this change, `HttpClient.get` retries a failed GET. It makes up to 3 attempts and waits 1 second, then 2 seconds, between attempts. A short blip no longer fails the nightly sync. A real outage still fails the sync with the same kind of error as today.

## Approach

**Chosen:** a loop inside `HttpClient.get`. The loop makes up to 3 attempts and waits 1 second, then 2 seconds. It retries timeouts, dropped connections, and the statuses 500, 502, 503, and 504. When all attempts fail, it raises the last error.

**Also chosen** (added by the planner, strike in review): one WARNING log line for each retry. Today nothing logs the status code, so nobody can see what a blip looks like. The log line also shows a retry during the staging run.

### Step 2: Retry `HttpClient.get` with backoff, and test it · `[ ]` AUTO · Parallel group: none

- **Do:**

  2. Add two keyword-only arguments to `HttpClient.__init__`: `max_attempts=3` and `backoff_base=1.0`. Keep `base_url` and `timeout` as they are.
  3. In `HttpClient.get`, repeat the `requests.get` call up to `max_attempts` times. Retry when the call raises `requests.Timeout` or `requests.ConnectionError`, or when the status is 500, 502, 503, or 504. Before attempt n+1, call `time.sleep(backoff_base * 2 ** (n - 1))`. The waits are 1.0 and then 2.0.
  4. After the last attempt, raise the last error. For a bad status, call `raise_for_status()` on the last response. A status outside the retry set, such as 404, raises at once with no retry.
  5. Write one WARNING log line for each retry. Give the path, the attempt number, and the reason.
  6. Do not add a named argument to `get`. Its `**params` collects the query parameters, so a named argument would take a query parameter from a caller.
  7. Leave `post` as it is.
  8. Create `tests/test_http_client.py`. Patch `requests.get`, `requests.post`, and `time.sleep` in `app.http_client`, so no test waits. Write these five tests:

     - A `requests.Timeout` then a 200: `get` returns the JSON body.
     - Three 503 responses in a row: `get` raises `requests.HTTPError` after exactly 3 calls.
     - One 404 response: `get` raises `requests.HTTPError` after exactly 1 call.
     - One 503 response on `post`: `post` raises `requests.HTTPError` after exactly 1 call, and `time.sleep` has 0 calls.
