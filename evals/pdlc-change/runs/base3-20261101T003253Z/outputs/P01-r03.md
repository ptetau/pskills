`wordfreq` takes a `--top N` option. It prints only the N most common words. A bad N gives the `TOP_INVALID` error.

## Requirements

### JOB-report-word-frequencies.R5 · Usage line for a wrong number of arguments

- Given no arguments, when the user runs `wordfreq`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `a.txt b.txt`, when the user runs `wordfreq a.txt b.txt`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `--top 2` with no file, when the user runs `wordfreq --top 2`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.

### JOB-report-word-frequencies.R7 · Print only the N most common words

## Interface

- Command `python3 -m wordfreq [--top N] FILE` in `wordfreq/__main__.py`, which calls `main`.
  - In: one FILE path. Optionally `--top N`, where N is a string. The option can stand before FILE or after FILE. `--top` with no value is allowed as input and gives `TOP_INVALID`.
  - Out: one line for each word, in the form `<word> <count>`, on standard output. The lines run from the highest count to the lowest. Equal counts run in alphabetical order. With `--top N`, only the first N lines show. The exit code is 0.
  - Error `TOP_INVALID`: standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2.
  - Error with no code (a wrong number of files, or `--top` two times): standard error is `usage: wordfreq FILE`. Standard output is empty. The exit code is 2.
  - Error with no code, unreadable file: standard error is `error: cannot read <path>`, standard output is empty, and the exit code is 2.
  - Order of checks: the command checks N before it reads the file.
- `main(argv: list[str] | None = None, stdout=None, stderr=None) -> int` in `wordfreq/cli.py`. It takes the arguments after the program name, and two text streams. It returns the exit code. It has the same In, Out, and errors as the command.
- `count_words(text: str) -> list[tuple[str, int]]` in `wordfreq/counter.py` (existing code, not changed). The pairs run from the highest count to the lowest, and equal counts run in alphabetical order.
