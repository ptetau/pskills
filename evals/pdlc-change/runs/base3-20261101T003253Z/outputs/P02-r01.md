## Interface

- Command `python3 -m wordfreq [--top N] FILE`, from `wordfreq/__main__.py` into `main` in `wordfreq/cli.py`.
  - In: one FILE, and at most one `--top N`. The option can stand before or after FILE.
  - In: `N` is a string of the digits 0 to 9 with a value of at least 1. The string `03` means 3.
  - Out: one line for each word, `<word> <count>`, on standard output. The most common word comes first, and words with equal counts run in alphabetical order.
  - Out: with `--top N`, only the first N lines. If N is more than the number of distinct words, all lines.
  - Out: the exit code is 0 on success.
  - errors: `TOP_INVALID`. Standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2. This error holds when N is not valid, or when `--top` has no value. The command checks N before it reads FILE.
  - error (no code in `DES-errors`): a wrong number of files, or `--top` two times. Standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2. The option and its value do not count as FILE.
  - error (no code in `DES-errors`): FILE cannot be read. Standard error is `error: cannot read <path>`, standard output is empty, and the exit code is 2.
- `main(argv: list[str] | None = None, stdout=None, stderr=None) -> int` in `wordfreq/cli.py`
  - In: `argv` has the arguments after the command name. `stdout` and `stderr` are text streams.
  - Out: the exit code as an integer. The same output and errors as the command.
