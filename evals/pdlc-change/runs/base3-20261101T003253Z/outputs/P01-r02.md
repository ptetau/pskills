# CH-0001 · Top option

## Delivers

The command `wordfreq` accepts `--top N` before or after FILE, and prints only the N most common words. A bad N, or a second `--top`, gives an error and exit code 2.

## Requirements

### JOB-report-word-frequencies.R5 · Usage line for a wrong number of arguments

The command needs exactly one FILE. The option `--top` and its value (see R7) do not count as FILE. If the number of files is not one, the command prints `usage: wordfreq FILE` to standard error (assumed), prints nothing to standard output, and exits with code 2.

- Given no arguments, when the user runs `wordfreq`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `a.txt b.txt`, when the user runs `wordfreq a.txt b.txt`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `--top 2` with no file, when the user runs `wordfreq --top 2`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.

### JOB-report-word-frequencies.R7 · Print only the N most common words

With `--top N`, the command prints only the first N lines of the output of R1 and R2. N must be a whole number greater than zero: one or more of the digits 0 to 9 (assumed), with a value of at least 1. The option can come before or after FILE (assumed). If N is more than the number of distinct words, the command prints all words (assumed). If words have the same count at the cut, the alphabetical order of R2 decides which words stay (assumed). If N is not valid, or `--top` has no value (assumed), the command prints `error: --top needs a whole number greater than zero` to standard error, prints nothing to standard output, and exits with code 2 (error code `TOP_INVALID`). The command checks N before it reads the file (assumed).

- Given a file with `b a b c a b`, when the user runs `wordfreq --top 2 FILE`, then the lines are `b 3` and `a 2`, and the exit code is 0.
- Given a file with `b a b c a b`, when the user runs `wordfreq FILE --top 2`, then the lines are `b 3` and `a 2`, and the exit code is 0.
- Given a file with `pear apple fig`, when the user runs `wordfreq --top 2 FILE`, then the lines are `apple 1` and `fig 1`.
- Given a file with `b a b c a b`, when the user runs `wordfreq --top 1 FILE`, then the output is `b 3`.
- Given a file with `b a b c a b`, when the user runs `wordfreq --top 10 FILE`, then the lines are `b 3`, `a 2`, `c 1`.
- Given a file with `b a b c a b`, when the user runs `wordfreq --top 03 FILE`, then the lines are `b 3`, `a 2`, `c 1`.
- Given an empty file, when the user runs `wordfreq --top 3 FILE`, then standard output is empty and the exit code is 0.
- Given any file, when the user runs `wordfreq --top 0 FILE`, then standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2.
- Given any file, when the user runs `wordfreq --top -1 FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq --top abc FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq --top 2.5 FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq --top 3.0 FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq --top +3 FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq --top 1e2 FILE`, then the result is the same error, with exit code 2.

## Interface

- Command `python3 -m wordfreq [--top N] FILE`, in `wordfreq/__main__.py`, which calls `main`.
  - In: `FILE` is one path. `--top N` is optional, and `N` is the next argument after `--top`.
  - In: `--top N` can stand before FILE (`--top 2 FILE`) or after FILE (`FILE --top 2`).
  - In: `N` can be a run of digits (`2`, `03`), or an invalid value (`0`, `-1`, `abc`, `2.5`, `3.0`, `+3`, `1e2`, or the empty string).
  - In: `--top` can have no value, as the last argument (`FILE --top`) or the only argument.
  - In: `--top` can appear two times (`--top 1 --top 2 FILE`).
  - Out: the lines of R1 and R2 (a word, a space, the count), most common first, with equal counts in alphabetical order. Without `--top`, all lines. With `--top N`, the first N lines only. Exit code 0.
  - errors: `TOP_INVALID`: standard error is `error: --top needs a whole number greater than zero`, standard output is empty, exit code 2. The command checks N before it reads the file.
  - Error with no code in `DES-errors`: usage. Standard error is `usage: wordfreq FILE`, standard output is empty, exit code 2. The cause is a number of files other than one, or `--top` two times.
  - Error with no code in `DES-errors`: unreadable file. Standard error is `error: cannot read <path>`, standard output is empty, exit code 2.
- `main(argv: list[str] | None = None, stdout=None, stderr=None) -> int` in `wordfreq/cli.py`
  - In: `argv` holds the arguments after the command name, in the forms above. `stdout` and `stderr` are text streams.
  - Out: the exit code as an `int`. The output goes to `stdout` and `stderr`.
  - errors: `TOP_INVALID`, and the usage and unreadable-file errors above.
