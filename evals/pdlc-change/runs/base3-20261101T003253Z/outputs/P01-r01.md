## Interface

- Command: `python3 -m wordfreq [--top N] FILE`, in `wordfreq/__main__.py`. The option can stand before or after FILE.
  - In: one FILE, and at most one `--top N`. N is a string of the digits 0 to 9 with a value of at least 1. A `--top` with no value, or an N that is not valid, is an error.
  - Out: one line for each word, as `<word> <count>`, most common first. Words with equal counts run in alphabetical order. With `--top N`, only the first N lines stay. If N is more than the number of distinct words, all lines stay.
  - Errors: `TOP_INVALID` prints `error: --top needs a whole number greater than zero` to standard error, prints nothing to standard output, and exits with code 2. N is checked before the file is read.
  - Errors: a wrong number of files, or `--top` two times, prints `usage: wordfreq FILE` to standard error, prints nothing to standard output, and exits with code 2.
  - Errors: a file that cannot be read prints `error: cannot read <path>` to standard error and exits with code 2. This error exists already.
- `main(argv: list[str] | None = None, stdout=None, stderr=None) -> int` in `wordfreq/cli.py`. It takes the arguments of the command, writes to `stdout` and `stderr`, and returns the exit code. This function exists already and keeps its signature.
- `count_words(text: str) -> list[tuple[str, int]]` in `wordfreq/counter.py`. It exists already and does not change.
