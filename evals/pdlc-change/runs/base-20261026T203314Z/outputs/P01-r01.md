# CH-0001 · Top option

Intent: IN-0001 · Scope: JOB-report-word-frequencies · Status: planned · Ticket: none · Branch: none · Base: main

## Delivers

When this change merges, the user can run `wordfreq --top N FILE` to see only the N most common words. The command refuses a bad N and a second `--top`, and it does not count `--top` and its value as a file.

## Requirements

### JOB-report-word-frequencies.R5 · Usage line for a wrong number of arguments

- Given no arguments, when the user runs `wordfreq`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `a.txt b.txt`, when the user runs `wordfreq a.txt b.txt`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `--top 2` with no file, when the user runs `wordfreq --top 2`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.

### JOB-report-word-frequencies.R7 · Print only the N most common words

- Given a file with `b a b c a b`, when the user runs `wordfreq --top 2 FILE`, then the lines are `b 3` and `a 2`, and the exit code is 0.
- Given a file with `b a b c a b`, when the user runs `wordfreq FILE --top 2`, then the lines are `b 3` and `a 2`, and the exit code is 0.
- Given a file with `pear apple fig`, when the user runs `wordfreq --top 2 FILE`, then the lines are `apple 1` and `fig 1`.
- Given a file with `b a b c a b`, when the user runs `wordfreq --top 1 FILE`, then the output is `b 3`.
- Given a file with `b a b c a b`, when the user runs `wordfreq --top 10 FILE`, then the lines are `b 3`, `a 2`, `c 1`.
- Given a file with `b a b c a b`, when the user runs `wordfreq --top 03 FILE`, then the lines are `b 3`, `a 2`, `c 1`.
- Given an empty file, when the user runs `wordfreq --top 3 FILE`, then standard output is empty and the exit code is 0.
- Given any file, when the user runs `wordfreq --top 0 FILE`, then standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2.
- Given any file, when the user runs `wordfreq --top -1 FILE`, then the result is the same error, with exit code 2.

## Interface

- `python3 -m wordfreq [--top N] FILE` in `wordfreq/__main__.py`. This is the command that the user runs. The file calls `main` (see the next entry).
  - in: the arguments after the program name. `FILE` is a path. `--top N` can come before or after `FILE`. `--top` takes the next argument as its value (assumed), also when that argument starts with `-` or is empty.
  - out: standard output holds one line `<word> <count>` for each word. The lines run from the highest count to the lowest, and equal counts run in alphabetical order. With `--top N`, standard output holds at most N lines. The exit code is 0.
  - errors: `TOP_INVALID`, when `--top` has no value or N is not a whole number greater than zero. The code does not show in the output. A check expects standard error `error: --top needs a whole number greater than zero`, empty standard output, and exit code 2.
  - other errors, which have no code in `DES-errors`: a check expects the exact message, empty standard output, and exit code 2.
    - `usage: wordfreq FILE`, when the number of files is not one or `--top` appears two times.
    - `error: cannot read <path>`, when the command cannot read the file.
  - order of the checks (assumed): the command checks the number of files and the count of `--top` first, then N, then it reads the file.
- `main(argv: list[str] | None = None, stdout: TextIO | None = None, stderr: TextIO | None = None) -> int` in `wordfreq/cli.py`. This function exists already, and its signature does not change.
  - in: the same arguments as the command, as a list of strings, without the program name. `stdout` and `stderr` are text streams. If a stream is `None`, the function uses the real stream.
  - out: the exit code, 0 or 2. The function writes the same text to `stdout` and `stderr` as the command writes.
  - errors: the same as the command.
