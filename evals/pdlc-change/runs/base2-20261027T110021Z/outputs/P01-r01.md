## Delivers

After this change merges, `wordfreq` accepts the `--top N` option. The option prints only the N most common words, and a bad N gives the error `TOP_INVALID`.

## Requirements

### JOB-report-word-frequencies.R5 · Usage line for a wrong number of arguments

- Given no arguments, when the user runs `wordfreq`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `a.txt b.txt`, when the user runs `wordfreq a.txt b.txt`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `--top 2` with no file, when the user runs `wordfreq --top 2`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.

### JOB-report-word-frequencies.R7 · Print only the N most common words

- Given a file with `b a b c a b`, when the user runs `wordfreq --top 2 FILE`, then the lines are `b 3` and `a 2`, and the exit code is 0.
- Given a file with `b a b c a b`, when the user runs `wordfreq FILE --top 2`, then the lines are `b 3` and `a 2`, and the exit code is 0.
- Given a file with `pear apple fig`, when the user runs `wordfreq --top 2 FILE`, then the lines are `apple 1` and `fig 1`.

## Interface

- `main(argv=None, stdout=None, stderr=None) -> int` in `wordfreq/cli.py`
  - in: `argv` is a list of strings, the arguments after the command name. It defaults to `sys.argv[1:]`. `stdout` and `stderr` are text streams. They default to `sys.stdout` and `sys.stderr`.
  - in: the optional `--top N` can come before or after FILE. N is the argument that follows `--top`, also when it starts with `-`. N is valid when it is one or more of the digits 0 to 9 and its value is at least 1. For example, `03` means 3.
  - out: the exit code. It is 0 on success and 2 for each error below. `main` writes one line `word count` for each word to `stdout`, and it writes each error line to `stderr`. Each line ends with a newline.
  - errors: `TOP_INVALID` writes `error: --top needs a whole number greater than zero`. N is missing, or N is not valid.
  - errors: the usage error has no code in `DES-errors`. It writes `usage: wordfreq FILE`. The number of files is not one, or `--top` appears two times. A check expects the exact message and the exit code 2.
  - errors: the cannot-read error has no code in `DES-errors`. It writes `error: cannot read <path>`. It exists already. A check expects the exact message and the exit code 2.
  - If more than one error applies, `main` gives the first of these (assumed): the usage error, then `TOP_INVALID`, then the cannot-read error. A wrong shape of arguments comes first, and the file is read last.
- The command `python3 -m wordfreq [--top N] FILE` in `wordfreq/__main__.py`
  - in: the same arguments as `main`, from the command line.
  - out: the same lines on standard output and standard error, and the exit code of `main`.
  - This file exists already, and this change does not edit it.
