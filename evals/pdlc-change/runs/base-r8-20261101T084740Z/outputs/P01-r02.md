# CH-0001 · Top option

Intent: IN-0001 · Scope: JOB-report-word-frequencies · Status: planned · Ticket: none · Branch: none · Base: main
Tests-Locked: none

## Delivers

The command `wordfreq` has a `--top N` option that prints only the N most common words. A bad N gives the `TOP_INVALID` error.

## Requirements

### JOB-report-word-frequencies.R5 · Usage line for a wrong number of arguments

- Given no arguments, when the user runs `wordfreq`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `a.txt b.txt`, when the user runs `wordfreq a.txt b.txt`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `--top 2` with no file, when the user runs `wordfreq --top 2`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.

### JOB-report-word-frequencies.R7 · Print only the N most common words

- Given a file with `b a b c a b`, when the user runs `wordfreq --top 2 FILE`, then the lines are `b 3` and `a 2`, and the exit code is 0.
- Given a file with `b a b c a b`, when the user runs `wordfreq FILE --top 2`, then the lines are `b 3` and `a 2`, and the exit code is 0.
- Given a file with `pear apple fig`, when the user runs `wordfreq --top 2 FILE`, then the lines are `apple 1` and `fig 1`.
- Given a file with `b a b c a b`, when the user runs `wordfreq --top 1 FILE`, then the output is `b 3`.
- Given a file with `b a b c a b`, when the user runs `wordfreq --top 10 FILE`, then the lines are `b 3`, `a 2`, `c 1`.
- Given a file with `b a b c a b`, when the user runs `wordfreq --top 03 FILE`, then the lines are `b 3`, `a 2`, `c 1`.
- Given an empty file, when the user runs `wordfreq --top 3 FILE`, then standard output is empty and the exit code is 0.
- Given any file, when the user runs `wordfreq --top 0 FILE`, then standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2.
- Given any file, when the user runs `wordfreq --top -1 FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq --top abc FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq --top 2.5 FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq --top 3.0 FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq --top +3 FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq --top 1e2 FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq --top "" FILE`, then the result is the same error, with exit code 2.
- Given any file, when the user runs `wordfreq FILE --top`, then the result is the same error, with exit code 2.
- Given no file `missing.txt`, when the user runs `wordfreq --top 0 missing.txt`, then standard error is `error: --top needs a whole number greater than zero` and the exit code is 2.
- Given no file `missing.txt`, when the user runs `wordfreq --top 2 missing.txt`, then standard error is `error: cannot read missing.txt` and the exit code is 2.

### JOB-report-word-frequencies.R8 · One --top option only

- Given a file with `b a b c a b`, when the user runs `wordfreq --top 1 --top 2 FILE`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.

## Interface

- `wordfreq [--top N] FILE` · command · `wordfreq/cli.py`
  - in: one FILE path. The option `--top N` can stand before or after FILE. N is one or more of the digits 0 to 9, with a value of at least 1. The option can appear one time.
  - out: standard output has one line for each distinct word: the word, a space, and the count. The lines run from the highest count to the lowest, and words with the same count run in alphabetical order. With `--top N`, standard output has only the first N lines. The exit code is 0.
  - errors: `TOP_INVALID` when N is missing or is not valid. Standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2. The command checks N before it reads FILE.
  - errors: with a number of files other than one, or with `--top` two times, standard error is `usage: wordfreq FILE`. Standard output is empty, and the exit code is 2.
  - errors: when FILE cannot be read, standard error is `error: cannot read <path>`, standard output is empty, and the exit code is 2.
