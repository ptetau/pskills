The command `wordfreq` has the option `--top N`. It prints only the N most common words, and gives the `TOP_INVALID` error for a bad N.

## Requirements

### JOB-report-word-frequencies.R5 · Usage line for a wrong number of arguments

- Given no arguments, when the user runs `wordfreq`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `a.txt b.txt`, when the user runs `wordfreq a.txt b.txt`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
- Given the arguments `--top 2` with no file, when the user runs `wordfreq --top 2`, then standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.

### JOB-report-word-frequencies.R7 · Print only the N most common words

- Given a file with `b a b c a b`, when the user runs `wordfreq --top 2 FILE`, then the lines are `b 3` and `a 2`, and the exit code is 0.

- Given a file with `b a b c a b`, when the user runs `wordfreq --top 03 FILE`, then the lines are `b 3`, `a 2`, `c 1`.
- Given an empty file, when the user runs `wordfreq --top 3 FILE`, then standard output is empty and the exit code is 0.

## Interface

- `python3 -m wordfreq FILE` · command · `wordfreq/__main__.py`
  - in: the path of one FILE, a text file in UTF-8
  - out: one line for each distinct word, as the word, a space, and the count. The lines run from the highest count to the lowest, and equal counts run in alphabetical order. The exit code is 0. A file with no words gives no output.
  - errors: none with a code in `DES-errors`. If the number of files is not one, standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2. If the file cannot be read, standard error is `error: cannot read <path>`, standard output is empty, and the exit code is 2.
- `--top N` · flag · `wordfreq/cli.py`
  - in: N, one or more of the digits 0 to 9, with a value of at least 1. The flag can stand before or after FILE. The user can give it one time.
  - out: only the first N lines of the output of the command. If N is more than the number of distinct words, all lines. Words with the same count at the cut stay in alphabetical order.
  - errors: `TOP_INVALID`, when N is not valid or the flag has no value. Standard error is `error: --top needs a whole number greater than zero`, standard output is empty, and the exit code is 2. The command checks N before it reads the file. If the flag stands two times, standard error is `usage: wordfreq FILE`, standard output is empty, and the exit code is 2.
