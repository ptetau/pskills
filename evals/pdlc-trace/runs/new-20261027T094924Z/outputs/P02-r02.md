## What the code does now

- `wordfreq --top N FILE` and `wordfreq FILE --top N` print only the N most common words. Ties at the cut follow the alphabetical order.
- A bad N prints `error: --top needs a whole number greater than zero` to standard error and exits with code 2. N must use the digits 0 to 9 only, so `03` works and `+3`, `3.0`, `1e2` fail.
- The command checks N before it reads the file.
- A repeated `--top` prints `usage: wordfreq FILE` and exits with code 2.
- `--top` and its value no longer count as the file. `wordfreq --top 2` with no file prints the usage line.
