## What the user sees now

- `wordfreq --top N FILE` and `wordfreq FILE --top N` print only the N most common words.
- Words with the same count at the cut stay in alphabetical order.
- A bad N prints `error: --top needs a whole number greater than zero` to standard error. The exit code is 2. The error code is `TOP_INVALID` (bad value of `--top`).
- A repeated `--top` prints `usage: wordfreq FILE` and exits with code 2.
- `wordfreq --top 2` with no file also prints the usage line.
